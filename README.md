## 3. Project Overview

Avalance is a digital showcase platform built for a specialized custom footwear brand, highlighting bespoke sneaker concepts, unique colorways, and urban footwear aesthetics. 

The site centers around presenting handcrafted sneaker designs and tailored apparel concepts. It offers visitors clear insight into the brand identity while enabling effortless browsing across all project sections. 

The initial build was constructed utilizing core HTML markup and custom CSS styling.

---

## 4. Website Goals and Objectives

The primary objectives for the Avalance web application comprise:

* Establishing a strong digital footprint for the Avalance brand.
* Presenting an exclusive catalog of custom sneakers and footwear concepts.
* Offering visitors comprehensive details regarding custom shoe orders and brand background.
* Maintaining an intuitive, user-friendly navigation layout.
* Encouraging users to explore the footwear gallery and product features.
* Providing accessible communication channels for prospective clients.

## [v2.0.0] - Part 2 Release (CSS & Responsive Design)
### Added
- External master stylesheet ('style.css') linked across all HTML pages.
- Universal CSS reset and custom property variables (':root').
- CSS Grid for product showcase gallery and Flexbox for site headers.
- Media query breakpoints targeting desktop (>992px), tablet (601px-992px), and mobile (<=600px) screens.
- Interactive pseudo classes (':hover', ':active', ':focus-visible') for user interactivity feedback.

### Changed
- Converted all static font measurements to relative units ('rem'/'em').
- Re-structured navigation layout for mobile touch compliance.
